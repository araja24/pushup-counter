# Only good reps count

Most counters count every completed movement and report form separately. PushForm advances the counter only for reps with no fault; a faulted rep is shown as rejected with its reason and the skeleton turns red while the body is out of alignment. The number on screen therefore means "push-ups done properly", which is the point of the product. The trade-off is that a user with consistently poor form sees a low number, so every rejection must carry a visible reason.
